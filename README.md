# Student Course Dashboard

## Description
The Student Course Dashboard is a React application that displays course information, lecturer names, completion statuses, and progress percentages.

## Features
- Reusable CourseCard component.
- Course data stored separately from the main application.
- Courses displayed using JavaScript's map() method.
- Course completion status displayed conditionally.
- Progress percentages and progress bars.
- Empty-state message when no courses are available.
- Responsive layout for smaller screens.

## Technologies Used
- React
- JavaScript
- CSS
- Vite

## How to Run the Project
1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL displayed in the terminal.
